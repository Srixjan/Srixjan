### 🔬 Projects

<table>
<tr>
<td>

**[🏦 LoanLens](https://github.com/Srixjan/Machine-Learning)** — Binary Classification · Loan Approval Prediction

**Preprocessing** — Mean imputation for numerical features, mode imputation for categorical · Label Encoding for ordinal (`Education_Level`) · One-Hot Encoding for nominal features (`Employment_Status`, `Marital_Status`, `Loan_Purpose`, `Property_Area`, `Gender`, `Employer_Category`) · StandardScaler for feature scaling

**Feature Engineering** — Polynomial features on `Credit_Score` and `DTI_Ratio` to capture non-linear relationships · Log transform on `Applicant_Income` to reduce skew

**Models Benchmarked** — Logistic Regression · KNN (k=7) · Gaussian Naive Bayes · evaluated on Precision, Recall, F1, and Accuracy

**Metric Priority** — Precision over Accuracy — minimizing false approvals matters more than overall correctness in a loan context

**Result** — Logistic Regression · `88% Accuracy` · `0.81 F1-Score`
